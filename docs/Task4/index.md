# ADR-STD-MVP-DepositRatesToCallCenter

**Номер:** ADR-STD-MVP-002
**Название задачи:** Передача ставок в кол-центр в рамках MVP
**Автор:** Александр Гусев
**Дата:** 2025-05-03

## Функциональные требования (Use Cases)

### UC1 — Просмотр ставок сотрудником кол-центра

* Сотрудник кол-центра входит в систему
* Открывает экран «Информация по депозитам»
* Видит список актуальных ставок по депозитам

### UC2 — Экспорт ставок в партнёрский кол-центр

* Менеджер банка обновляет ставки (в XLS или в новой форме АБС)
* Система по расписанию генерирует CSV-файл со ставками
* Файл автоматически сохраняется в согласованной папке, доступной партнёру

## Нефункциональные требования (FURPS+)

* **Безопасность**: выгружаемый файл не содержит персональных данных
* **Совместимость**: выгрузка совместима с текущей системой партнёра (CSV формат)
* **Поддерживаемость**: решение можно развивать в будущем — например, добавить API интеграцию
* **Производительность**: передача файла и доступ к ставкам должны выполняться менее чем за 1 секунду внутри систем
* **Надёжность**: система не должна зависеть от прямого доступа к АБС (учитываем перегрузку)

## Решение

### Диаграмма контекста (C4: System Context)

```puml
@startuml
!includeurl https://raw.githubusercontent.com/plantuml-stdlib/C4-PlantUML/master/C4_Context.puml

Person(client, "Клиент")
System_Boundary(std_bank, "Банк Стандарт") {
    System(ibs, "АБС")
    System(ib, "Интернет-банк")
    System(callcenter, "Система кол-центра")
    System(partnercc, "Партнёрский кол-центр")

Rel(client, callcenter, "Уточнение ставок по телефону")
Rel(ib, callcenter, "Просмотр ставок сотрудником")
Rel(xls_proc, ibs, "Загрузка/Обновление ставок")
Rel(xls_proc, callcenter, "Экспорт ставок (в файл)")
Rel(xls_proc, partnercc, "Выгрузка CSV-файла")
@enduml
```

```puml

Rel(ib_ui, ib_api, "REST")

Rel(callcenter_api, ms_sql, "JDBC/SQL")

Rel(xls_sync, callcenter_api, "HTTP - получение обновлений")
```

## Альтернативы

1. Подключить кол-центр напрямую к АБС

   * **Недостаток**: увеличивает нагрузку на систему, нарушает принцип изоляции

2. Реализовать REST API выгрузки ставок для партнёров

   * **Недостаток**: текущая внешняя система не поддерживает интеграции по API

## Недостатки и ограничения

* Поддержка CSV-выгрузки требует дополнительной логики обработки ошибок (например, если файл не доставлен)
* Не все ставки персонализированы — при звонке клиенту нужно будет делать уточнение через бэк-офис вручную
* Сотрудники могут получать ставки с задержкой до следующей выгрузки, если нет live API
