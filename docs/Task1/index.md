## Диаграмма интеграции приложений

```puml
@startuml
skinparam rectangle {
  BackgroundColor #E6F2FF
  BorderColor Black
}
actor Client
actor Employee as "Сотрудник отделения"
actor CallCenterOperator as "Оператор кол-центра"
actor BackOffice as "Сотрудник бэк-офиса"
actor CreditManager as "Кредитный менеджер"

rectangle "Сайт (PHP + React.js)" as Site
rectangle "Интернет-банк\n(ASP.NET MVC + MSSQL)" as OnlineBank
rectangle "АБС\n(Delphi + Oracle, PL/SQL)" as ABS
rectangle "Кол-центр\n(React.js + Java, PostgreSQL)" as CallCenter
rectangle "СМС-шлюз\n(поддержка IT-отдела)" as SMSGateway
rectangle "Система расчёта ставок\n(Excel-файл)" as ExcelRates
rectangle "Почта (e-mail)" as Mail
rectangle "Резервный ЦОД" as DR

Client --> Site : Подача заявки на депозит
Site --> CallCenter : Передача обращения
CallCenterOperator --> CallCenter : Работа с обращениями
CallCenter --> ABS : Создание обращения
ABS --> SMSGateway : Отправка СМС клиенту
Employee --> ABS : Ввод заявки клиента
ABS --> Mail : Отправка письма в бэк-офис
BackOffice --> ExcelRates : Расчёт ставки
BackOffice --> Mail : Ответ с расчётом ставки
Mail --> Employee : Получение ставки
Employee --> ABS : Создание депозита, загрузка документов
CreditManager --> ABS : Расчёт кредитного риска (для спец. ставки)
ABS --> DR : Резервное копирование / переключение

@enduml
```
